What is Python?

- Python is a programming language.
- It's creater is Guido Van Rossum.
- Released in 1991.
- Used for: + Web Development + Software Developement + Mathematics

What can Python Do?

- It can be used on server to create web application.
- It can be used alongside softwares to create workflows.
- It can connect to database systems and can read and modify Files.
- It can be used to handle Big Data and perform complex mathematics.

Why Python?
